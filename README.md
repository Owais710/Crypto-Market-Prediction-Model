# Crypto Price Direction Predictor (XGBoost + Binance + Streamlit)

This project is a **crypto market direction prediction** application built using:

- **Binance API** for historical crypto data
- **XGBoost** for machine learning
- **Streamlit** for web deployment

The model predicts whether the **next hourly candle** for a selected coin will go **UP or DOWN**.

---

## 🔥 Features

✔ Predicts price direction for **10 cryptocurrencies**  
✔ Uses technical indicators (EMA, RSI, MACD, Volatility)  
✔ Separate XGBoost model for each coin (highest accuracy)  
✔ Streamlit UI for real-time prediction  
✔ No API key required for historical data  
✔ Easy to deploy (Streamlit Cloud / HuggingFace Spaces)
